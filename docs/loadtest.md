## Setup

- **Hardware:** NVIDIA GeForce GTX 1650 (4.0 GB) · Intel64 Family 6 Model 158 Stepping 10, GenuineIntel · 15.8 GB RAM · torch 2.11.0+cu128
- **Model:** `birefnet_lite` · max_batch=4 · workers=1
- **Queue:** in-process (fakeredis)
- **Mode:** standalone · client and server on the same machine (no network hop)
- **Run:** 2026-10-03 14:28:19 · git `None`

### Caveats

- No Redis/Valkey server was reachable, so the queue ran in-process (fakeredis). Queue semantics are the same, but there is no network hop, no fsync and no cross-process contention — real deployments will be somewhat slower.
- Client and server share one machine, so client CPU competes with preprocessing.
